# Varti — портфолио

![Превью](preview.png)

Сайт-портфолио в виде 3D-витрины. Каждый проект — предмет, собранный кодом на three.js:

| Проект | Предмет | Что он делает |
|---|---|---|
| «Утро» — лендинг кофейни | чашка кофе с латте-артом | над ней поднимается пар |
| Напоминалка — Telegram-бот | телефон | на экране сами появляются сообщения переписки с ботом |
| Запись и админ-панель | ноутбук | раскрывается, графики в админке «вырастают» |
| Сгущёнка из Рогачёва | банка | приоткрывает крышку |
| SEKUNDA — 3D-конфигуратор | часы | стрелки показывают настоящее время |

## Как устроено

- **Первый экран.** Предметы парят вокруг надписи VARTI. Если навести мышь, появляется название проекта, а по клику страница переходит к нему.
- **Прокрутка.** Каждый предмет по очереди выезжает вперёд рядом с карточкой своего проекта, остальные уходят в глубину. Цвет подсветки меняется под проект.
- **Карточки проектов:** описание, что сделано, технологии, кнопки «Открыть сайт» и «Код на GitHub», скриншот сайта.
- **Дальше на странице:** «Обо мне» с навыками и тем, как проходит работа, и «Контакты» с кнопкой Telegram.
- **Детали:**
  - собственный курсор;
  - «магнитные» кнопки;
  - наклон скриншотов за мышью;
  - боковая навигация по проектам;
  - пылинки в воздухе.
- **Телефоны.** Предмет показывается сверху, а карточка под ним. Если устройство не успевает, чёткость 3D понижается автоматически.
- **Без 3D.** Если браузер не поддерживает 3D, текст и карточки всё равно показываются.

## Как открыть

Дважды щёлкните `index.html`. Нужен интернет: библиотека three.js и шрифты загружаются из сети.

## Как опубликовать на GitHub Pages (адрес `varti214.github.io`)

1. Создайте на GitHub публичный репозиторий с названием **`varti214.github.io`**. Такое название — особое: сайт откроется прямо по адресу `https://varti214.github.io/`, без лишних слов в ссылке.
2. Загрузите в него `index.html`. `preview.png` и `README.md` по желанию.
3. Откройте **Settings → Pages → Deploy from a branch → main / (root) → Save**.
4. Через пару минут сайт откроется по адресу **https://varti214.github.io/**.

## Где что менять

Всё в одном файле `index.html`:

| Что | Где искать |
|---|---|
| Тексты проектов, ссылки на сайты | разметка `<section class="project">` |
| Telegram и GitHub | ссылки `t.me/Varti_ls` и `github.com/Varti214` |
| Цвета подсветки проектов | массив `PROJECTS` в скрипте |
| Положение предметов на каждом экране | объект `POSES` и массив `FOCUS_S` |
| Переписка на экране телефона | массив `CHAT_SCRIPT` |
| Экран админки на ноутбуке | функция `drawAdmin` |
| Скриншоты сайтов | объект `SHOTS` в самом конце файла |

## Технологии

HTML, CSS, JavaScript, [three.js](https://threejs.org) r170 (WebGL), шрифты Geologica и Onest.
